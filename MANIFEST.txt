=== FEATURES ===

✓ Execute custom JavaScript on any webpage
✓ Inject custom CSS styles on any webpage
✓ Three matching modes:
  - URL contains string
  - Page contains element (CSS selector)
  - Both URL and element match
✓ Bootstrap 5 Dark theme UI
✓ Add, edit, delete, and toggle rules
✓ Persistent storage (synced across browser)
✓ Multiple rules support
✓ Visual rule indicators (type badges, JS/CSS badges)
✓ Chrome and Firefox compatible

=== QUICK INSTALL ===

Chrome:
  1. chrome://extensions/
  2. Enable "Developer mode"
  3. Click "Load unpacked"
  4. Select the chrome/ folder

Firefox:
  1. about:debugging#/runtime/this-firefox
  2. Click "Load Temporary Add-on"
  3. Select firefox/manifest.json

=== USAGE ===

1. Click Greasemonkey icon in toolbar
2. Click "+ Add Rule"
3. Configure:
   - Name your rule
   - Choose match type
   - Enter URL pattern and/or element selector
   - Add JavaScript and/or CSS code
4. Save and reload target page
